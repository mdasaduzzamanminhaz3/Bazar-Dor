# 🛒 বাজার দর (BazarDor)

**BazarDor** is a modern, real-time daily commodity price tracker in Bangladesh. Built for transparency and ease of use, it helps consumers stay informed about current market prices for essential grocery items—including rice, lentils, oil, vegetables, fish, meat, and spices—across various markets and divisions.

---

## 🚀 Key Features

1. **📊 Real-time Price Insights & Trends:** Get immediate visibility into daily product prices, price changes (percentage increase/decrease), and price comparisons relative to yesterday.
2. **🏙️ Market & Division-wise Breakdown:** View detailed market breakdowns to discover minimum, maximum, and average prices across different divisions and local bazaars.
3. **⚡ High-Performance Data Caching & Streaming:** Built with Next.js App Router server components and ISR (Incremental Static Regeneration) for lightning-fast page loads and minimal latency.
4. **🎨 Tailored Bengali UI & Skeleton Loaders:** Fully localized Bengali language interface, responsive layouts, and pulse-skeleton loaders to eliminate visual layout shifts (CLS) during data fetching.
5. **🎯 Smooth Local Navigation:** Instant anchor-based smooth scrolling to product lists without full page refreshes or unnecessary route changes.

---

## 🛠️ Technologies Used

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
- **Typography:** [Google Fonts (Hind Siliguri)](https://fonts.google.com/specimen/Hind+Siliguri)
- **API Endpoint:** Worker REST API for live market data
